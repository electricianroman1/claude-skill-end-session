# Закрытие процесса сессии

Каждая открытая сессия держит свой процесс `claude.exe` (~250 МБ). Приложение само его не завершает, когда пользователь уходит из сессии. Скрипт завершает процесс, не архивируя сессию: история цела, при открытии сессии процесс создаётся заново (проверено 28.10.2026).

Скрипт: `C:\Users\PX\.claude\skills\end-session\close-session.ps1` (PowerShell 5.1, файл с BOM — не пересохранять без BOM). Без `-Apply` ничего не завершает.

## Порядок
1. **Текущая сессия** («сессия завершена»): если менялись файлы проекта — одной строкой дописать итог в `JOURNAL.md` проекта (новые записи сверху), коротко сказать, что сделано и что осталось открытым. Затем последним действием:
   `powershell -File "C:\Users\PX\.claude\skills\end-session\close-session.ps1" -Self -Apply`
   Скрипт сам завершит процесс через 12 с, когда ответ уже закончен и сессия простаивает (мгновенное убийство посреди хода даёт в приложении окно «Сессия прервана»). После вызова написать одну короткую прощальную фразу и закончить ход — больше никаких вызовов инструментов.
2. **Другая сессия** («закрой сессию LEDKeeper2»): сначала без `-Apply` с `-Title "<часть названия>"`, показать пользователю, какой процесс будет закрыт, и после его «да» — с `-Apply`. Не закрывать сессию, в которой сейчас идёт работа.
3. **Список**: `-List` показывает PID, память и название каждой сессии.

## Ограничения
- Сопоставление процесса и сессии: по `--resume=<id>` в аргументах, иначе по времени создания (±5 с). Если процесс не найден — сказать об этом, ничего не угадывать.
- Совпадающие названия («Оптимизация проекта для LLM» у нескольких сессий): `-Title` закроет все совпавшие — перед `-Apply` показать список и уточнить.
- Не использовать архивацию (`archive_session`), если пользователь не просил.
